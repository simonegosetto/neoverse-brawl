# Changelog

All notable changes to Neoverse Brawl will be documented in this file.

## [1.0.0] - 2024-11-18

### 🎉 Initial Release

#### Core Features
- ✅ Voice input integration (Web Speech API)
- ✅ Claude AI character generation
- ✅ Real-time 2D combat system
- ✅ Multiplayer local (2 players)
- ✅ 6 preset characters for testing
- ✅ Menu system with Quick Test mode
- ✅ Round-based combat with timer
- ✅ Special energy system
- ✅ Ultimate moves
- ✅ Responsive controls (keyboard)

#### Technical Implementation
- ✅ Phaser 3 game engine
- ✅ TypeScript for type safety
- ✅ Vite for fast development
- ✅ Modular scene architecture
- ✅ Fighter entity system
- ✅ Character data structures

#### Documentation
- ✅ Comprehensive README
- ✅ Quick Start guide
- ✅ Technical documentation
- ✅ Code examples for extensions
- ✅ Deployment configuration

## Bug Fixes & Improvements

### Known Issues
- Voice recognition may not work in Firefox (use Chrome/Edge)
- Claude API calls may fail without internet
- Performance may degrade with many particles

### Planned Fixes

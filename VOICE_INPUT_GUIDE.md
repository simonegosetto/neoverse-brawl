# 🎤 Voice Input Guide - Come Creare Personaggi Epici

## 📝 Tips per Input Vocali Efficaci

### Regola d'Oro
**Sii specifico ma conciso!** Hai solo 5 secondi.

### Formula Base
```
[Tipo] + [Elemento/Tema] + [Caratteristica Unica]
```

---

## ✅ Esempi di Input BUONI

### Striker (Veloce, Combo)
- ✅ "Un ninja veloce con kunai elettrici"
- ✅ "Pugile cyborg con jet boots"
- ✅ "Spadaccino samurai con lame infuocate"
- ✅ "Ballerina letale con ribbons taglienti"

**Perché funzionano:** Chiaro tipo + elemento distintivo + meccanica implicita

### Bruiser (Melee Pesante)
- ✅ "Un orso gigante con armatura di ferro"
- ✅ "Lottatore sumo con potere sismico"
- ✅ "Viking berserker con ascia a due mani"
- ✅ "Golem di roccia indistruttibile"

**Perché funzionano:** Enfasi su forza/resistenza + visual distintivo

### Zoner (Attacchi Distanza)
- ✅ "Mago del ghiaccio con shards volanti"
- ✅ "Arciere elfico con frecce esplosive"
- ✅ "Scienziato pazzo con ray gun"
- ✅ "Stregone del vento che controlla tornado"

**Perché funzionano:** Abilità ranged chiare + element theming

### Summoner (Evocazioni)
- ✅ "Domatore di draghi con tre wyvern"
- ✅ "Necromante che evoca scheletri"
- ✅ "Alchimista con golem d'oro"
- ✅ "Sciamano spirituale con totem animali"

**Perché funzionano:** Chiaro cosa viene evocato

### Tank (Alta Difesa)
- ✅ "Cavaliere in armatura completa indistruttibile"
- ✅ "Robot transformer con scudo energetico"
- ✅ "Tartaruga ninja gigante con guscio d'acciaio"
- ✅ "Guardiano di pietra con barriera magica"

**Perché funzionano:** Focus su protezione/resistenza

### Wildcard (Creativo/Meme)
- ✅ "Gatto con laser eyes e teleport"

- ✅ "Hacker digitale che glitcha la realtà"

## ❌ Esempi di Input POCO EFFICACI

### Troppo Vaghi
- ❌ "Un guerriero forte"
  - → ✅ "Un gladiatore romano con tridente"

- ❌ "Uno veloce"
  - → ✅ "Un ghepardo mutante cyberpunk"

- ❌ "Con poteri magici"
  - → ✅ "Mago delle tempeste con fulmini"

### Troppo Complessi (>5 secondi)
- ❌ "Un samurai che viene dal futuro con spade laser blu e armatura nera che può trasformarsi in drago"
  - → ✅ "Samurai cyborg con dragon mode"

- ❌ "Un tipo che ha tanti poteri diversi, tipo fuoco e ghiaccio insieme, e anche può volare"
  - → ✅ "Stregone elementale con fire e ice"

### Contradittori
- ❌ "Tank velocissimo"
  - Il sistema bilansia automaticamente, ma è confuso
  - → ✅ "Guerriero pesante" oppure "Scout veloce"

## 🎯 Ottimizzazione per Archetype

Se vuoi un archetype specifico, usa queste parole chiave:

### Per STRIKER
Parole chiave: veloce, ninja, combo, agile, rapido, dash
```
"Ninja veloce shadow strike"
"Assassino agile dual daggers"
```

### Per BRUISER
Parole chiave: pesante, forte, wrestler, brutale, melee
```
"Lottatore brutale power bomb"
"Guerriero pesante giant hammer"
```

### Per ZONER
Parole chiave: mago, arciere, distanza, proiettili, controllo
```
"Mago distanza ice shards"
"Arciere elfico piercing arrows"
```

### Per SUMMONER
Parole chiave: evoca, domatore, sciamano, minions, famiglio
```
"Necromante evoca zombie army"
"Sciamano spirit totem beasts"
```

### Per TANK
Parole chiave: difesa, scudo, armatura, indistruttibile, wall
```
"Cavaliere difesa tower shield"
"Golem indistruttibile stone armor"
```

### Per WILDCARD
Parole chiave: strano, glitch, random, chaos, meme
```
"Gatto glitch reality bender"
"Chef chaos spaghetti weapons"
```

## 📊 Voice Input Analysis

### Optimal Length
- **2-4 parole**: ⭐⭐⭐ Perfetto
- **5-7 parole**: ⭐⭐ Buono
- **8+ parole**: ⭐ Rischio taglio

### Best Time Distribution
- 1s: Tipo base (ninja, mago, tank)
- 2s: Caratteristica (veloce, potente)
- 1.5s: Abilità/elemento (fuoco, laser)
- 0.5s: Detail extra

### Clarity Matters
- Pronuncia chiaramente
- Evita riempitivi ("uhm", "tipo", "cioè")
- Rallenta leggermente
- Ambiente silenzioso
